# LofiStack Component Gallery

**Live:** https://lofistack-component-gallery.vercel.app  
**Author:** Arnab Biswas · LofiStack 90 Day Build Challenge — Track A (Component Gallery)

30 reusable UI components, each with its own page at `/components/<slug>` showing a live preview with
state controls, a typed props table, a usage example and the build prompt.

## Stack

- Next.js (App Router) + React + TypeScript (strict)
- Tailwind CSS v4 — every component is styled with utility classes; colours come from per-component CSS variables so each one has a light and a dark theme
- Hosted on Vercel, statically generated

## Structure

```
app/
  (site)/page.tsx                 homepage: all components + weekly agent logs
  (site)/components/[slug]/       one page per component
  embed/[slug]/                   chrome-free preview used by the homepage cards
components/
  gallery/<slug>/
    <Component>.tsx               the reusable component (typed props)
    demo.tsx                      live preview + controls
    meta.ts                       title, week, type, props docs, usage, prompt
    sample.ts                     sample data and build prompt
    tokens.css                    light/dark design tokens
  site/                           gallery shell (nav, code block, props table, controls)
lib/
  registry.ts · demos.ts          generated by scripts/gen-registry.mjs
  agent-logs.tsx                  Track B entries shown on the homepage
```

## Adding a component (2 per week)

1. Create `components/gallery/<slug>/` with the five files above (copy an existing folder as a starting point).
2. Set `number` and `week` in `meta.ts`.
3. `npm run dev` — the registry regenerates automatically and the page appears at `/components/<slug>`.

## Scripts

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build (regenerates the registry first)
npm run lint     # type-check
```
